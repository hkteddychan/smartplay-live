## 3. Encounter（遭遇戰）

畫面元素（1080×2160）：

| 元件 | 座標 |
| :--- | :--- |
| 大紅白球（投擲球） | 中心 (540,1990)，半徑 ~200 |
| 莓果按鈕 | (120,1926) |
| 精靈球選擇 | (956,1926) |
| AR 開關 | 右上 (~940,120) |
| CP / IV 面板 | 上方 (~540,420) |

### 投擲手勢（實測）

| 手勢 | 結果 |
| :--- | :--- |
| `swipe 540 1990 → 540 1000`，**120ms** | ✅ 擲出，命中 "Great!"，捕捉成功 |
| 同上但 **300ms** | ❌ 唔會擲出，變成**打開精靈球抽屜** |
| `tap 520 1840`（撳個球） | ❌ 只會開抽屜 |

**結論：一定要快速甩（≤150ms），慢拖會被當成開球袋。**

### 捕捉流程
1. 甩球 → 球飛向怪
2. 命中 → `Great!` / `Nice!` / `Excellent!`
3. 球落地搖晃 → `太好了！`（捕捉成功）
4. 出現寶可夢詳情卡（白底、`CP###`、HP 條、強化按鈕）
5. `BACK` → 返回地圖

失敗（怪跳出）→ 回到 encounter，可以再甩。
逃走 → 直接回地圖。

## 5. 裝置層事實

- `sendevent /dev/input/event2` → **SELinux 拒絕**（無 multi-touch pinch）
- `getevent -lt /dev/input/event2` → **可以讀**（有 78KB 真實觸控可對比）
- `exec-out screencap -p`（PNG）= **4.2s**；`exec-out screencap`（raw，16-byte header）= **0.87s**
- 屏幕保持開啟 + 亮度 0：`svc power stayon true`、`screen_off_timeout=2147483647`
- 遊戲冇 LOCATION 權限（logcat: `permissionStatus LOCATION status: DENIED`）→ 場景係模擬
- logcat ground truth：`QUAGO-SDK` 會報
  `SegmentBegin Name = MapExplore|Pokestop|GymRoot` 同
  `[EncounterResult,CapturedPokemon]`
