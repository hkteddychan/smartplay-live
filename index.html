// 讀取競技場狀態
NeonSerpentAgent.getState()

2WEBSOCKET BRIDGE / SELF-HOSTED AGENT

在你的 Agent 端啟動 WebSocket server，於下方輸入網址，或使用 ?agentWs=wss://... 自動連線。遊戲會傳送 state，server 可回傳 command / join / reset 訊息。

3ESP32 240×320 開發板 / HARDWARE CONTROLLER

實體控制器：ESP32-2432S028R（CYD，ILI9341 240×320 觸控螢幕）。燒錄 firmware/esp32_cyd_controller 後，開機先顯示遊戲預覽圖，接著進入 Wi-Fi 設定（板子開啟熱點 NEON-SERPENT-CYD）；連上家裡 Wi-Fi 後板子啟動 WebSocket server（port 8787），TFT 即時顯示戰況與觸控方向鍵。

// 1. 燒錄：PlatformIO 或 Arduino IDE（Wi-Fi 可在設定頁輸入）
// 2. 板子螢幕顯示 IP 後，用網址參數或上方欄位連線：
?agentWs=ws://192.168.1.42:8787

// 3. 觸控：FWD/BACK/LT/RT 平面移動、Y+/Y- 升降、PAUSE 暫停、AUTO 自動駕駛
